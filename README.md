# Forecasting Long-Term Electricity Market Duck Curves: A Decoupled Ridge–XGBoost Approach

Code and data for the paper by Ángel Arcos Vargas and Luis Galiana Fajardo, proposing a hybrid Ridge Regression + XGBoost model to forecast the Spanish day-ahead electricity price profile (2026–2035) as a percentage of the monthly mean, without recursive feedback.

> **Revised version (November 2026).** The data and code now correspond to the revised manuscript:
> the model output is floored at 0 % and renormalised so that every month has a mean of 100 %;
> the solar constraint on the trend cells has been removed; and the analyses added during the
> revision are included (`revision_analyses/`). The projected hours with price ≤ 0 are
> **913 (2026), 2,524 (2030) and 3,116 (2035)**. The previous release is available in the Git history.

## Contents

### `data/`
- **`spain_electricity_price_pct_monthly_average_2019_2035.xlsx`** (and the same table as `.csv`) — hourly dataset 2019–2035 with date and time, day type (*Working Day* / *Holiday* = weekend or Spanish national public holiday), historical/projected flag, and price as % of the monthly average. 2019–2025 are observed values; 2026–2035 are the model's projection. Generated by `hybrid_model_code/final_projection.py`.
- **`omie_spain_hourly_prices_2016_2025.csv`** — model input: OMIE hourly day-ahead prices for the Spanish bidding zone (EUR/MWh). Columns: `Fecha` (date), `hora` (hour 1–24), `Precios` (price), `Año` (year).
- **`observed_prices_2026_jan_oct.csv`** — observed January–October 2026 prices used for the out-of-sample check (OMIE for January–September, Ember for October), with the monthly mean (`P_mes`), the price as % of the monthly mean (`x`) and the weekly naive values (`precio_naive`, `x_naive`, t − 168 h).

Sources: OMIE (https://www.omie.es) and Ember (https://ember-energy.org, CC BY 4.0).

### `hybrid_model_code/`
Python implementation of the hybrid model, five comparison baselines (Holt-Winters, SARIMAX, Prophet, LSTM, N-BEATS), the ablation study and the backtesting/comparison harness.

| Script | Purpose |
|---|---|
| `data_utils.py` | Data loading, target definition, post-processing (floor at 0 % + monthly renormalisation), metrics |
| `model_ridge_xgboost.py` | Proposed hybrid model (cell-wise Ridge trend + XGBoost on residuals) |
| `model_ridge_only.py`, `model_xgboost_only.py` | Ablation models |
| `model_holtwinters.py`, `model_sarima.py`, `model_prophet.py`, `model_lstm.py`, `model_nbeats.py` | Comparison baselines |
| `run_comparison.py` | Runs all models: 2025 blind backtest and 2026–2035 projections |
| `final_projection.py` | **Final 2026–2035 projection** (training 2019–2025) → `data/spain_electricity_price_pct_monthly_average_2019_2035.*` |
| `fair_comparison_postprocessed.py` | Same post-processing applied to all alternatives; trend continuity (Fig. 9) |
| `ablation_comparison.py`, `rolling_ablation.py`, `ablation_nonpositive_hours.py` | Ablation studies (incl. hours with price ≤ 0) |
| `horizon_error_analysis.py`, `plot_projected_uncertainty.py`, `compare_band_methods.py` | Error vs. horizon and the empirical error band |
| `projection_stability.py`, `stratified_error_analysis.py` | Stability and stratified error analysis |
| `alpha_sweep_and_backtest_figures.py` | Sweep of the Ridge penalty α and backtest figures |

`predictions/` holds the 2025 backtest predictions of every method and `tables/` the result tables. The 2026–2035 projections of the baselines are not stored (≈40 MB); `run_comparison.py` regenerates them.

### `revision_analyses/`
Analyses added during the revision. Results are written to `revision_analyses/results/`.

| Script | Purpose |
|---|---|
| `sensitivity.py` | Sensitivity to the solar constraint, the training window and the trend degree |
| `dm_tests_band_coverage.py` | Diebold–Mariano tests, 2025 backtest in EUR/MWh, coverage of the 95 % error band |
| `normalisation_eur.py` | Alternative normalisations of the target and EUR/MWh errors with an ex-ante price level |
| `check_2026.py` | Out-of-sample check of the projection with the observed January–October 2026 prices |

## Reproducing the results

```bash
pip install -r requirements.txt
cd hybrid_model_code
python final_projection.py          # final projection and data/ tables (about 15 s)
python run_comparison.py            # all models (the deep-learning baselines take longer)
python fair_comparison_postprocessed.py
cd ../revision_analyses
python check_2026.py
python sensitivity.py
python dm_tests_band_coverage.py
python normalisation_eur.py
```

Results were produced with Python 3.11, numpy 2.4, pandas 3.0, scikit-learn 1.8, xgboost 3.2, statsmodels 0.14, prophet 1.3 and torch 2.13.
