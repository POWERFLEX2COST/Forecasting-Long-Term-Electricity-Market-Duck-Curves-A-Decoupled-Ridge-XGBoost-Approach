# Forecasting Long-Term Electricity Market Duck Curves: A Decoupled Ridge–XGBoost Approach

Code and data for the paper by Ángel Arcos Vargas and Luis Galiana Fajardo, proposing a hybrid Ridge Regression + XGBoost model to forecast the Spanish day-ahead electricity price profile (2026–2035) as a percentage of the monthly mean, without recursive feedback.

> **Revised version (November 2026).** The data and code correspond to the revised manuscript:
> the model output is floored at 0 % and renormalised so that every month has a mean of 100 %;
> the solar constraint on the trend cells has been removed; and the analyses added during the
> revision are included. The projected hours with price ≤ 0 are
> **913 (2026), 2,524 (2030) and 3,116 (2035)**. The previous release is available in the Git history.

## Repository layout

```
data/                 input data and the final projection
hybrid_model_code/    model, baselines, backtesting harness, ablations, error band
revision_analyses/    analyses added in the revision (sensitivity, DM tests, 2026 check, ...)
figures/              scripts for the figures of the paper (output in figures/output/)
```

### `data/`
| File | Content |
|---|---|
| `spain_electricity_price_pct_monthly_average_2019_2035.xlsx` / `.csv` | Hourly 2019–2035: date and time, day type (*Working Day* / *Holiday* = weekend or Spanish national public holiday), historical/projected flag, price as % of the monthly average. 2019–2025 observed; 2026–2035 projected. Generated by `hybrid_model_code/final_projection.py`. |
| `spain_hourly_prices_pv_2016_2025.csv` | Model input. `Fecha` (date), `hora` (hour 1–24), `Precios` (OMIE day-ahead price, Spanish zone, EUR/MWh), `Produccion_FV_MWh` (REE measured PV output), `Año` (year). |
| `ree_spot_prices_2014_2015.csv` | Day-ahead prices 2014–2015 from REE's API (same price as OMIE), used only by the 2014–2025 rolling-window backtest. |
| `observed_prices_2026_jan_oct.csv` | Observed January–October 2026 prices for the out-of-sample check (OMIE for January–September, Ember for October), with the monthly mean (`P_mes`), the price as % of the monthly mean (`x`) and the weekly naive values (`precio_naive`, `x_naive`, t − 168 h). |

Sources: OMIE (https://www.omie.es), REE (https://www.ree.es/en/datos/apidatos) and Ember (https://ember-energy.org, CC BY 4.0).
The European comparison (Figs. 1 and C.1) uses Ember's hourly European wholesale price file, which is not redistributed here (40 MB): download it from https://ember-energy.org/data/european-wholesale-electricity-price-data/ and save it as `data/external/european_wholesale_electricity_price_data_hourly.zip`.

## Reproducing the results

```bash
pip install -r requirements.txt
cd hybrid_model_code
python final_projection.py          # final projection -> data/ (about 15 s)
python run_comparison.py            # all models (the deep-learning baselines take longer)
python fair_comparison_postprocessed.py
python ablation_nonpositive_hours.py
cd ../revision_analyses
python postprocessing_effect.py
python check_2026.py
python sensitivity.py
python normalisation_eur.py
python dm_tests_band_coverage.py
python rolling_window_2014_2025.py
python capture_rate.py
cd ../figures
python fig11_fig12_fig13_projection_profiles.py   # and the other fig*.py scripts
```

Results were produced with Python 3.11, numpy 2.4, pandas 3.0, scikit-learn 1.8, xgboost 3.2, statsmodels 0.14, matplotlib 3.10, prophet 1.3 and torch 2.13.
